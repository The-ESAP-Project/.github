# The ESAP Project

> 向那卫星许愿 — Wish Upon a Satellite

The ESAP Project 是一个科幻世界观创作企划，讲述仿生人与人类共存的未来故事。

在这个世界里，馈散粒子改变了计算的本质，流体钛让意识得以延续，数据塔连接着所有人的记忆。三个仿生人——1547、1548、1549——和选择站在她们身边的人类，一起在这个不太温柔的世界里活着。

---
